## 🛠️ MCP Tool Specification

### `inspect_agent_output`

| Parameter | Type | Required | Description |
| :--- | :--- | :---: | :--- |
| `agent_output` | `string` | **Yes** | The textual or code output generated by an LLM or sub-agent to inspect. |
| `is_code` | `boolean` | No | Set to `true` if inspecting executable Python or shell code for AST risks. (Default: `false`) |
| `context_ground_truth` | `string` | No | Factual reference / ground-truth context to verify numerical consistency. |
