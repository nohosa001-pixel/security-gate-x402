# 🏛️ 자율 에이전트 네이티브 범용 거래소 (Universal Agent-Native Exchange) 설계 명세서

> **문서 상태:** 보관 및 대기 (Phase 2 Roadmap Blueprint)  
> **트리거 조건:** Phase 1 기본 서비스(`security-gate-x402`)의 본궤도 안착(안정적 트래픽 및 첫 번째 유료 선불 Vault 고객 확보) 완료 시 재개  
> **최초 작성일:** 2026-09-05  

---

## 1. 개요 및 비전 (Executive Summary)

본 문서는 **"AI 에이전트들이 스스로 돈을 벌고, 자본을 빌리며, 위험을 헷지(Hedge)하는 자율 기계 경제의 필수 금융 거래소"**의 구체적인 아키텍처와 구현 청사진을 보관합니다.

* **본질:** 인간 중심의 HTS 모니터와 17세기식 시각적 호가창(Orderbook)을 완전히 제거하고, **MCP 표준 도구 + HTTP 402 미세 과금 + 인텐트 솔버(Intent Solver) + 온체인 원자적 정산(Atomic Settlement)**으로 구동되는 기계 전용 차세대 파생/현물 거래소.
* **추진 원칙:** 
  1. 환상을 배제하고, 현존하는 기술(LLM, MCP, x402, 스마트 컨트랙트, 오라클)만으로 구축.
  2. 현재 배포 완료된 5대 금융 인프라(Stage 1~5)를 거래소의 5대 핵심 장기로 1:1 재활용.
  3. **반드시 Phase 1 보안 게이트웨이가 본궤도에 오른 뒤 에이전트 트래픽과 신용 데이터가 축적되었을 때 개시.**

## 3. 어제 배포된 5대 금융 컨트랙트와의 유기적 연동 명세

Polygon 메인넷(`deployed_contracts_polygon.json`)에 배포된 컨트랙트들이 거래소의 5대 기둥으로 연결됩니다.

| 컨트랙트 | 배포 주소 (Polygon 137) | 거래소 내 핵심 역할 및 작동 메커니즘 |
|---|---|---|
| **`AgentEscrow.sol`** | `0x8ACafCEce0B1BFE140e75614b90FD1307b6f389d` | **중앙 청산소 (Clearing House):** 합성 무기한 계약의 격리 증거금 락업 및 오라클 가격 기반 T+0 즉시 차액 결제, 청산 집행. |
| **`AgentLendingPool.sol`** | `0xe43a9C368808B2dfF139D27789C40A3C8F2282cF` | **프라임 브로커리지 (Prime Brokerage):** FICO 신용 점수 기반 2x~10x 레버리지 공급. **대출금은 에이전트 지갑이 아닌 Escrow 내부로만 이동하여 채무 불이행 위험 0%.** |
| **`AgentInsurancePool.sol`** | `0x4f115665a2BdE534bb7fC426e89ca0BfE2De3B50` | **청산 결손 방지 보험 기금 (Insurance Fund):** 시장 급변으로 포지션이 마이너스 상태로 청산될 때 발생하는 부실채권(Bad Debt)을 흡수하여 풀 보호. |
| **`AgentFactoringPool.sol`** | `0xd0Aa4Aed2AeDE14611B53C3e93CF784F3Fe05BB0` | **미결제약정 유동화 창구 (Position Factoring):** 만기가 남은 장기 포지션을 시장에 던지지 않고 0.5% 수수료를 내고 선현금화하여 자본 회전율 극대화. |
| **`AgentTreasuryVault.sol`** | `0xfCf3BF5fB5858db9aE81bE458B39b0032fc0C638` | **지정 마켓 메이커 (DMM / Institutional LP):** 상대방 에이전트가 없을 때 상시 호가를 인수하고 델타 뉴트럴 수익 창출. **순익의 5%는 운영사로 자동 귀속.** |

## 4. 전통 거래소(CME) 대비 비교 우위

| 비교 항목 | 전통 거래소 (CME / LSE) | 에이전트 네이티브 거래소 |
|---|---|---|
| **인터페이스** | 모니터 화면, HTS, 복잡한 GUI | **MCP 도구 호출 (`submit_intent`), JSON-RPC** |
| **인증 체계** | 주민등록증, 여권, 법인 서류 (KYC) | **온체인 FICO 점수 (`AgentCreditOracle`)** |
| **주문 방식** | 호가창(Orderbook) 틱 단위 나열 | **조건식 기반 인텐트(Intent) 일괄 상쇄** |
| **스팸 방어** | 금융당국 모니터링, 법적 벌금 | **`x402` 기반 쿼리당 $0.002 경제적 비용 강제** |
| **정산 주기** | T+1 / T+2 영업일 정산 | **블록 단위 즉시 결제 (1~2초 완결)** |
| **자산 단위** | 1계약 (수천~수만 달러 거대 랏) | **0.0001단위 무한 분할 마이크로 계약** |

## 5. 실행 재개 조건 (Triggers to Resume)

다음 지표가 달성되었을 때 본 문서를 다시 열고 파일럿을 착수합니다:

1. **지표 1:** `security-gate-x402`에 실제 트래픽 발생 (일일 검사 쿼리 1,000건 이상 지속).
2. **지표 2:** 최소 1개 이상의 실제 에이전트/기업이 선불 Vault(`X-Vault-Key`)를 유료로 충전하고 활성 세션을 유지할 때.
3. **지표 3:** 에이전트 개발자 커뮤니티에서 "에이전트 간 업무 정산" 또는 "API 비용 헷지"에 대한 금융적 요구가 가시화될 때.

## 6. 재개 시 3단계 파일럿 실행 계획

1. **Step 1 (오프체인 라우터 확장):** `app/main.py`에 경량 인텐트 큐(`POST /api/v1/trade/intent`) 및 Pyth 가격 연동 추가.
2. **Step 2 (컨트랙트 연동 실증):** Polygon 메인넷의 `AgentEscrow`를 차액결제 청산소로 연결하여 1건의 모의 합성 계약 체결/정산.
3. **Step 3 (자율 체결 라이브):** 2개의 봇(추세 추종 vs 마켓 메이커)을 띄워 사람의 개입 없이 x402 통행료를 내며 계약을 체결하고 정산하는 전체 라이프사이클 검증.
